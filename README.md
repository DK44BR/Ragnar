# 🤖 Ragnar

> Plataforma modular de IA e Robótica baseada em ESP32, Raspberry Pi e Inteligência Artificial.

---

## Objetivo

O Ragnar é um sistema modular para desenvolvimento de assistentes inteligentes, automação e robótica.

O projeto integra:

- ESP32
- Raspberry Pi
- IA Local
- Sensores
- Automação residencial
- Visão computacional
- Controle por voz
- Memória persistente
